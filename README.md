# นับแต้มธนู · สถิติการยิง

แอปบันทึกคะแนนยิงธนู เก็บสถิติ กลุ่มลูก และสร้างเป้าแบบกำหนดเองได้ ใช้งานออฟไลน์ได้

- **เว็บ:** https://lukkaree.github.io/archery-score/
- **APK (Android):** ดูหน้า [Releases](../../releases/latest) → `archery-score.apk`

ทุกครั้งที่แก้ไฟล์แล้ว commit GitHub Actions จะ build เว็บและ APK ใหม่ให้อัตโนมัติ
APK ใหม่ติดตั้งทับของเดิมได้ ข้อมูลไม่หาย (อย่าลบ `debug.keystore`)

ข้อมูลเก็บในเครื่องผู้ใช้แต่ละคน — ย้ายเครื่องด้วย *ตั้งค่า → ส่งออก/นำเข้า JSON*
